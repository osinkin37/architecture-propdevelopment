Task 3:

I. Требования к безопасности:
а) Все коммуникации системы должны применять криптографические средства защиты (шифрование). При использовании TLS, не допускается использование версии ниже 1.2;
б) Пользователь, авторизованный в системе, должен иметь доступ только к той функциональности, которая необходима для функционирования системы;
в) Все действия систем по вызову внешнего API должны проходить логирование.

II. Протоколы аутентификации и авторизации
а) Подключения к системе должны проходить аутентификацию и авторизацию;
б) Поддержка передачи сведений о пользователях и правах доступа через токены JWT после успешной авторизации;
в) Применение API ключей для идентификации систем при вызове API

III. Взаимодействие между системами предприятия и внешней платформой
а) Компоненты системы должны иметь минимально необходимый набор привилегий в части межсервисного взаимодействия, сетевых доступов и обращений к ресурсным системам;
б) Интеграция происходит по стандарту REST API и протоколу HTTPS
